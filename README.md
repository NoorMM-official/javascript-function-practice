
# JavaScript Function & Logic Practice

A structured collection of JavaScript practice assignments designed to strengthen programming fundamentals, functional thinking, and problem-solving skills.

## Overview

This repository contains practical JavaScript exercises covering functions, arrow functions, conditional statements, loops, string manipulation, and mathematical operations.

Each assignment focuses on applying core JavaScript concepts to solve real-world style programming problems.

## Concepts Covered

- JavaScript Functions
- Arrow Functions
- Parameters and Arguments
- Return Statements
- Conditional Statements
- `if`, `else if`, and `else`
- `for` Loops
- String Methods
- Number Conversion
- Mathematical Methods
- Basic Calculations
- Problem-Solving & Logic Building

## Practice Assignments

### 01. Password Strength Checker
Evaluates password strength by checking its length and the presence of uppercase letters, lowercase letters, and numbers.

### 02. Cinema Ticket Billing System
Calculates ticket costs, applies discounts based on customer type and ticket quantity, and determines the final payable amount.

### 03. Game Score Analyzer
Analyzes a score by calculating the number of digits, sum of digits, and square root, then classifies the score according to predefined conditions.

### 04. Temperature Checker
Classifies a temperature as Hot, Cold, or Normal using conditional logic and a loop-based checking counter.

### 05. Student Result Calculator
Calculates total marks and percentage, then assigns a grade based on predefined percentage criteria.
